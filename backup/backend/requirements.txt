# Document extraction (ingestion/). Every one of these is import-guarded: a
# host that hasn't installed them still ingests every format, because the
# OOXML formats are ZIP+XML and ingestion/extractors.py has a stdlib fallback
# for each. What these buy is quality, and one capability that has no fallback:
#   pdfplumber   — PDF text, the best of the three backends tried
#   pymupdf      — PDF text AND rasterising a SCANNED pdf's pages for vision.
#                  Without it, a PDF with no text layer cannot be read at all.
#   python-docx  — .docx tables and heading levels (fallback flattens them)
#   openpyxl     — .xlsx with formula results (fallback reads cached values)
#   python-pptx  — .pptx speaker notes (fallback reads slide text only)
#   pillow       — image dimensions, format conversion (BMP/TIFF/HEIC → PNG)
#                  and downscaling oversized images to fit the vision limit
pdfplumber
pymupdf
python-docx
openpyxl
python-pptx
pillow
